# PentestGPT v2 — IoT 韌體自動化滲透測試框架

利用 **固定流程(SOP)** 搭配 **Agent AI**,對 IoT 韌體進行半自動化滲透測試,並自動產出最終滲透測試報告。

## 設計理念

本系統採 **「固定流程為主、Agent AI 為輔」** 的半自動化架構:

- **資料蒐集與流程推進**(資產偵察、Web 列舉、裝置指紋、漏洞檢索)皆由**固定流程**驅動,確保每個階段穩定、可重現,不受小型語言模型的不確定性影響。
- **僅在「漏洞驗證」階段**引入 **Agent AI**,由其針對檢索到的 CVE 動態產生並執行驗證測試。
- 流程結束後**自動彙整為滲透測試最終報告**。

## 使用方式

### 方式一:透過網頁選擇靶機

執行 `openWeb.sh` 開啟網頁後,選擇目標 IoT 靶機:

\`\`\`bash
./openWeb.sh
\`\`\`

### 方式二:指定韌體啟動

\`\`\`bash
./run.sh "韌體名稱"
\`\`\`

- 韌體檔案位於:`Firmware/Firmware_tool/firmware-analysis-plus/fw_bin`
- **新增韌體**:將韌體的 `.bin` 檔放入上述資料夾即可。

### 重新啟動 Agent 容器

若韌體靶機已啟動完畢,可重新開啟 `ai_agent` 容器:

\`\`\`bash
./Docker/restartAI.sh
\`\`\`
